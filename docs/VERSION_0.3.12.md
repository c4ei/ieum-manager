# IEUM Manager v0.3.12 — 이음마당·길드

## 지금까지 결정한 내용

`iem.aah.name`의 친근한 이름은 **이음마당**입니다. 검증자는 **이음지기**, 위임은 **이음 맡기기**, 지급액은 **함께 키운 보상**, 기간형 일반 지갑 보상은 **들고만 있어도 받는 응원 보상**으로 부릅니다.

길드명과 지역/주제는 사용자가 정합니다. 길드장과 이음지기는 별개입니다. 길드는 레벨 1~5이고 정원은 20/40/60/80/100명입니다. 내부 등급은 `새싹 → 길드원 → 운영진 → 부길드장 → 길드장`입니다. 인기 점수는 현재 회원 1명당 10점, 이벤트 1개당 5점이며 초기에는 발견 순위·배지·이벤트 기회에만 씁니다. 코인을 자동 지급하면 봇·자전 가입으로 조작할 수 있어 제외했습니다.

## 길드 생성비

1 IEUM을 재단지갑 `0x356456fF1216B57a6f8891b195b42d296789B67D`로 보냅니다. API는 AAH 로그인, 송신 지갑, 수신 재단지갑, 1 IEUM 이상, 인덱서에 포함된 확정 블록, 거래 해시 미사용을 모두 검사합니다. 개인키는 Manager에 저장하지 않습니다.

## 신고와 포상

길드·길드원·이벤트를 신고할 수 있고 사유와 증거, 접수/검토/인정/기각, 포상 후보/승인/지급 상태를 보존합니다. 이번 버전은 접수 API와 데이터 구조를 추가했습니다. 포상은 운영자 검토 후 수동 승인하며 자동 송금하지 않습니다. 다음 버전에는 관리자 검토 화면, 피신고자 소명, 신고율 제한, 중복·담합 탐지, 개인정보 보존 기간, 이의 신청을 추가해야 합니다.

## 운영 적용

`db/init.sql`을 적용한 뒤 Manager를 재시작합니다. 기존 공급량 RPC의 `Bal_All`, `Bal_Utong_All`, `Bal_Lock_All`과 구형 필드 양쪽을 읽도록 호환 처리했습니다.

검증: `node --check server.js && npm test`
