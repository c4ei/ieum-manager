## 1. 제품 방향

IEUM을 단순한 "새 코인"으로 소개하면 수많은 블록체인 프로젝트 사이에서 묻힐 가능성이 높다. IEUM은 코인 가격이나 수익률보다 **AI 시대에 사용자의 돈과 개인정보에 대한 최종 결정권을 지키는 생활형 보안 제품**으로 공개한다.

### 대표 문장

> **IEUM — AI에게 일을 맡기되, 돈과 개인정보의 최종 결정권은 사용자가 갖는 Wallet**

### 보조 문장

> 온라인 Wallet, 오프라인 서명, 가족 보호, 제한된 AI 권한을 하나로 연결합니다.

대외 소개에서는 `한국형 블록체인`, `PoS`, `연 5%`, `가격 상승`보다 위 문장을 먼저 사용한다. 기술과 경제 정책은 투명하게 공개하되 제품 가치의 근거로 배치한다.

## 2. 세 가지 대표 제품

### 2.1 IEUM AI 금고 — 첫 대표 제품

AI가 사용자를 대신해 행동할 때 권한 범위와 결제 조건을 Wallet에서 제한하고, 중요한 결정은 사용자가 직접 승인하는 기능이다.

핵심 기능:

- AI 또는 Agent별 사용 권한
- 일·월 사용 금액 한도
- 허용 사이트·가맹점 목록
- 특정 금액 이상 생체인증 또는 재확인
- API 자동결제 한도
- 가족 공동 승인
- 즉시 전체 권한 정지
- 모든 승인·거절·취소 기록

초기 MVP는 실제 카드 자동결제까지 연결하지 않아도 된다.

```text
AI가 상품·결제 요청 준비
→ IEUM Wallet이 설정 조건 검증
→ 사용자가 최종 승인
→ 서명된 승인 기록 보관
```

현재 구현 여부를 반드시 표시하고, 시제품·계획 기능을 실제 제공 기능처럼 표현하지 않는다. 참고 모델: [Google Agent Payments Protocol(AP2)](https://github.com/google-agentic-commerce/AP2).

### 2.2 IEUM SafeKey Duo — 첫 실물 제품

> 두 개의 USB로 온라인과 오프라인 자산관리를 직접 배우는 보안 키트

권장 구성:

- Vault USB
- Bridge USB
- 복구 카드
- IEUM Cold Wallet
- IEUM Wallet 설치 도구
- 한글·영문 설명서
- 100 Test IEUM
- 최대 0.1~1 Mainnet IEUM의 소규모 체험 보상

메인넷 IEUM을 제품 가격의 주된 가치로 내세우지 않는다. 실물 구성, 학습 경험, 오프라인 서명과 복구 절차가 제품의 핵심 가치다.

### 2.3 IEUM Pass — 생활 확장 제품

- 비밀번호 없는 로그인
- 회원증
- 쿠폰·스탬프
- 상품권
- 영수증·보증서
- 가족 안심 기능
- IEUM Pay 연결

Pass는 AI 금고와 SafeKey에서 확보한 신뢰·서명 체계를 실제 생활 서비스로 확장하는 단계다.

## 4. 10분 체험 흐름

방문자가 다음 세 단계를 10분 안에 완료할 수 있어야 한다.

1. IEUM Wallet 설치
2. Test IEUM 수령 및 간단한 송금
3. AI 권한 설정 또는 Cold Wallet 오프라인 서명 체험

기본 체험은 테스트넷에서 제공한다. 메인넷 보상은 소액으로 제한하고 지급 조건, 총예산, 계정당 제한을 공개한다.

## 11. 의사결정 기준

1. 사용자가 AI에 넘긴 권한을 이해하고 제한할 수 있는가?
2. 사용자가 돈과 개인정보의 최종 결정을 직접 내릴 수 있는가?
3. 승인·거절·취소 기록을 나중에 검증할 수 있는가?
4. 일반 사용자가 10분 안에 핵심 가치를 체험할 수 있는가?
5. 첫 100명의 실제 사용 증거를 만들 수 있는가?

## 12. 최종 제품 정의

> IEUM의 첫 대표 제품은 **AI 금고**이고,  
> 첫 실물 제품은 **SafeKey Duo**이며,  
> 실제 생활 확장은 **IEUM Pass**다.

IEUM은 비트코인처럼 될 필요가 없다. 100명이 실제로 자신의 AI 권한을 Wallet으로 제한하거나, Cold Wallet으로 안전하게 서명하거나, 상품권을 한 번이라도 사용한다면 이미 이름뿐인 코인과 다른 제품이 된다.
