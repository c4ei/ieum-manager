# IEUM Manager v0.3.9 관리자·WAF·관제 개선

## 관제 정확성

- 확정 인증서가 20개 미만이면 낮은 서명률을 장애로 단정하지 않고 `표본 부족`으로 표시합니다.
- 평균 블록 시간은 높이 1 이상의 운영 블록끼리 계산하여 genesis 대기 시간을 제외합니다.
- 검증자의 precommit 서명 수와 블록 생성 수를 별도 표시합니다.
- 표본 20개 이후 95% 미만은 WARNING, 80% 미만은 CRITICAL입니다.

## 실제 관리자 작업

관리자는 `/admin.html`에서 Manager와 인덱서가 사용할 RPC 노드를 차단하거나 우선순위 0~100을 설정하고 관제 캐시를 즉시 새로고침할 수 있습니다. 변경과 인증 실패는 `logs/admin-audit.jsonl`에 기록되며 모든 노드를 동시에 차단하는 요청은 거부합니다.

우선순위는 조회 소스 선택에만 적용됩니다. 검증자의 PoS 투표권, 블록 보상, 제안자 선정 확률을 높이지 않습니다. Chain v0.22.7에는 인증된 P2P 영구 차단 및 검증자 집합 변경 RPC가 없으므로 해당 작업은 지원하지 않습니다.

## WAF

- 관리자 API 분당 30회, 공개 요청 분당 180회 제한
- 관리자 본문 최대 16 KiB, JSON 및 동일 Origin만 허용
- 관리자 토큰 5회 실패 시 해당 IP를 15분 차단
- 경로 탐색, `.env`, `.git`, WordPress 스캐너 요청 차단
- CSP, frame 차단, MIME sniff 차단과 권한 정책 적용

운영에서는 Caddy `basic_auth` 또는 Cloudflare Access를 1차 방어로 유지하고 Manager 포트는 LAN 또는 localhost에서만 접근시켜야 합니다.
