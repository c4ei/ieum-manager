# IEUM Manager v0.3.7 IEUM 수량 표시 버그 수정

## 원인

- Explorer 화면은 최소 단위 정수를 `10^18`로 정수 나눗셈하여 소수부를 모두
  버리고 있었습니다.
- Manager API의 다른 잔액 포맷은 소수점 6자리에서 잘라 Explorer와 표시 규칙이
  달랐습니다.

## 수정 내용

- 서버와 Explorer 모두 `BigInt` 정수 연산만 사용합니다.
- 18자리 원시 정밀도는 유지하고 화면 표시만 소수점 8자리에서 반올림합니다.
- 뒤쪽 0은 제거합니다. `99.23100000 → 99.231`, `99.99990000 → 99.9999`입니다.
- 반올림으로 정수 경계를 넘는 경우 `99.999999996 → 100`으로 표시합니다.
- 운영 지갑 잔액, 계정 잔액, 최근 온체인 흐름, Explorer 거래 목록·주소·검색 결과에
  같은 규칙을 적용했습니다.

## 검증

```bash
npm ci
npm test
docker compose config
```

배포 후 브라우저 캐시를 강력 새로고침하고 실제 소액 거래의 잔액과 Explorer 수량이
같이 표시되는지 확인합니다.
