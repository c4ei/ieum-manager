이 상품권은 먼저 정상 등록한 한 사람에게 한 번만 지급됩니다.

STEP 1 · 지갑 준비

IEUM 지갑이 있으신가요?

현재 기기확인 중…

Wallet 설치 안내

공식 Light Wallet 다운로드Normal Wallet 보기공식 배포처: github.com/c4ei/ieum-wallet · 현재 안내 버전 1.0.2.1
  1. 운영체제에 맞는 공식 설치 파일을 내려받습니다.
  2. Wallet을 실행하고 새 지갑을 만든 뒤 안전하게 백업합니다.
  3. Wallet에서 받기 주소(0x…)를 복사합니다.
  4. 이 상품권 화면으로 돌아와 주소와 교환번호를 입력합니다.

상품권 링크와 교환번호를 함께 다른 사람에게 보내지 마세요.

Ubuntu 개발자용 실행 방법

일반 사용자는 `.deb` 또는 `.AppImage` 설치를 권장합니다. 소스 개발 환경에서만 다음 명령을 사용하세요.

git clone https://github.com/c4ei/ieum-wallet.git
cd ieum-wallet
npm ci
npm run tauri dev

STEP 2 · 상품권 받기

받는 방법

  1. IEUM Wallet에서 내 지갑 주소를 복사합니다.
  2. 아래에 주소와 상품권 뒷면의 교환번호를 입력합니다.
  3. 내용을 확인하고 내 지갑으로 받기를 누릅니다.

운영자는 지갑 비밀번호·복구 문구·개인키를 요구하지 않습니다. 이 화면에는 받을 주소와 상품권 교환번호만 입력하세요.
